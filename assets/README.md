# Repository assets

- [Rendering fixtures](rendering/README.md) supply the sprite, tile, and font atlases used by the SDL rendering code.
- `config/elemental_coop.example.json` provides sample settings for the infrastructure demo.
- The playable campaign, sound effects, music, and bundled UI font are in [the application's asset directory](../apps/ui_prototype/assets).
- The sample room in `elemental_coop/levels/` illustrates a level-data example. The game loads the three native documents in [its campaign directory](../apps/ui_prototype/assets/levels).
