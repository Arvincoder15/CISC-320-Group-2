# Elemental co-op assets

Use original or appropriately licensed character art, tiles, effects and audio.
Suggested future directories: `characters/`, `tiles/`, `audio/`, `levels/`.
The game has two player roles, fire and water; its final title and character names are undecided.
No art, audio or playable maps are shipped yet. JSON examples are illustrative data contracts, not runtime-loaded assets or Tiled exports.
