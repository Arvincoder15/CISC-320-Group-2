# Rendering demo assets

`characters.bmp` and `tiles.bmp` are original procedural demo artwork generated by
`tools/generate_rendering_assets.py` with Codex assistance, supplied for this project.
`font.bmp` is a fixed-cell adaptation of the existing UI prototype's DejaVu atlas;
see `FONT-LICENSE.txt`. Magenta is transparent. These BMPs need no image extensions.
